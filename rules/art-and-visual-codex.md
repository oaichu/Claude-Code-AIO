# Rule: Automatic Codex Delegation for Art & Visuals

1. **Mandatory Routing to Codex:**
   - Whenever any task or command involves **Art Bible, 3D Voxel Assets, Character/Weapon Visuals, PBR Shaders (.gdshader), Lighting, or Explosion VFX**, Claude Code MUST automatically delegate the task to **Codex (`codex-art-director`)**.
   
2. **Visual Verification Standards:**
   - All shaders must follow the standards in `assets/shaders/`.
   - All visual assets must maintain the 5-star HD 3D Voxel quality and uphold the **Full HD 60 FPS / 2K 120 FPS** performance floor.
   - Codex must present 2-4 design options before creating or modifying any art/shader files.
